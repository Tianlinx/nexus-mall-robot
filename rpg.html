数据挖掘真的进了机制

Classification 分类决策树判定动态障碍类型，产出碰撞风险 R，进入 Cost 与耗电。
Clustering 聚类K-means 把 25 条通道分低/中/高拥挤，影响移动速度与电池消耗。
Regression 回归多元线性回归由通道长度/宽度/客流预测通行时间 T，进入 ETA。
Association 关联Apriori/ECLAT 规则推荐加购，经 §5.3 兼容性校验后加入订单。
Path planning 路径A* 距离矩阵 + Held–Karp 精确排序；A*/Dijkstra/Greedy/BFS 四算法对照扩展节点数。
Cost 五因子Cost = w₁D + w₂C + w₃T + w₄R + w₅H，可切换 §7.5 加权边权。

v9.1 运行时避障

  • 下一格或安全间距受阻 → 立即局部 A* 绕障；仅无可行绕路时短暂等待 0.6 s 重试，连续 5 次失败才上报路段阻塞。
  • 双方贴近时让行实体沿垂直方向侧移 0.7 m 并继续推进，同时从动态占用栅格中剔除，窄通道不再互锁。
  • 取货后按 leg 重算剩余路线，终点不再连回中间点；段切换触发重绘。
  • 红线未动：几何、16 组基线、seed 20261113、服务时间 S 独立于通行时间 T、Cost 与 w₁–w₅。

地图、客流与交易均为教学合成数据，非真实卖场实测；价格与经营规则为游戏化设定。
